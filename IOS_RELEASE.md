# Duet: iOS / TestFlight

## Конфигурация

- EAS build/submit profile: `app-store`.
- Имя: `Duet`; bundle identifier: `app.duet.mobile`.
- Только iPhone (`supportsTablet: false`).
- Настоящее устройство, магазинная подпись (`distribution: store`), не симулятор.
- Версия приложения берётся из `app.json`; номер сборки хранится в EAS и увеличивается автоматически.
- Для iOS используется production environment EAS. Профили Android остаются отдельными.

## До первой облачной сборки

1. Дождаться активации Apple Developer Program (статус Pending должен исчезнуть).
2. Проверить доступ к App Store Connect и принять необходимые соглашения.
3. Проверить доступ к Expo-проекту `gasello/duet`.
4. Проверить production environment в Expo: `EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `EXPO_PUBLIC_SUPPORT_EMAIL`. Локальный `.env` исключён из загрузки EAS и не заменяет облачные переменные.
5. Проверить, что `EXPO_PUBLIC_STORE` не переопределён облачным окружением: профиль должен использовать `app-store`.
6. Проверить доступность bundle identifier `app.duet.mobile` в своём Apple Team. Не менять его после первой публикации.
7. Подготовить сертификат Apple Distribution и provisioning profile через EAS. Для push-уведомлений настроить APNs key. Не добавлять ключи, пароли и сертификаты в Git.
8. Выбрать поддерживаемый Expo образ macOS/Xcode, соответствующий действующим требованиям App Store. Локальный экспорт JS не проверяет Xcode/CocoaPods.

## Сборка на Windows

Из корня проекта:

```powershell
npx eas-cli@latest login
npx eas-cli@latest build --platform ios --profile app-store
```

При первом запуске пройти вход Apple и настройку подписи. Apple Team ID и App Store Connect app ID не зашиты в проект: их нужно выбрать из реального аккаунта.

## Загрузка

```powershell
npx eas-cli@latest submit --platform ios --profile app-store
```

Выбрать нужную iOS-сборку в диалоге. Загрузка не публикует приложение публично.
После обработки открыть App Store Connect → TestFlight, заполнить сведения о шифровании по фактической реализации, создать внутреннюю группу, добавить свой аккаунт и установить сборку через TestFlight.
`usesNonExemptEncryption` намеренно не задан: ответ необходимо подтвердить перед загрузкой, а не выставлять для обхода вопроса.

## Проверки на iPhone 12

- Чистая установка, регистрация, вход, повторный запуск, выход, восстановление пароля.
- Соединение пары и синхронизация с другим клиентом.
- Важные даты, вопросы дня, желания, комментарии и фотографии.
- Разрешение и отказ в доступе к фото и уведомлениям.
- Локальные напоминания и удалённые push, открытие нужного экрана по уведомлению.
- Потеря сети, повторное подключение, возврат из фонового режима.
- Клавиатура, safe area, длинный текст, увеличенный системный шрифт.
- Смена альтернативной иконки и повторный запуск.
- Удаление тестового аккаунта и проверка связанных данных.

## Перед публичной модерацией

- Заполнить карточку, App Privacy, возрастной рейтинг и страны распространения.
- Опубликовать доступные страницы поддержки и политики конфиденциальности.
- Подготовить реальные скриншоты в требуемых Apple размерах.
- Проверить privacy manifests SDK и предупреждения обработки сборки.
- Подготовить демонстрационные аккаунты пары и инструкцию для модератора.
- Проверить требования к пользовательскому контенту и обработке жалоб.
- Выбрать проверенную сборку и ручной выпуск после одобрения.
