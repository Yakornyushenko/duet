# Скриншоты Google Play

Сюда нужно сохранить шесть финальных скриншотов с Android-устройства или эмулятора:

- `01-home.png`
- `02-dates.png`
- `03-wishes.png`
- `04-notes.png`
- `05-question.png`
- `06-statistics.png`

Использовать одно вертикальное разрешение для всего набора. Перед съёмкой включить светлую тему, скрыть системные уведомления и заполнить приложение только демонстрационными данными.

Не использовать реальные email, имена, фотографии, коды приглашений и интимные ответы.
