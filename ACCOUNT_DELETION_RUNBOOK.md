# Обработка запроса на удаление аккаунта Duet

Эта инструкция предназначена только для разработчика Duet. Пользователь может отправить запрос на `Duet.support@proton.me`, если не может удалить аккаунт внутри приложения.

Для учёта обращений создать в почте три папки или метки:

- `Удаление — новые`;
- `Удаление — ожидают подтверждения`;
- `Удаление — выполнено`.

Письма с темой `Удаление аккаунта Duet` помещать в `Удаление — новые`. Срок отсчитывать от даты, когда владение аккаунтом подтверждено.

## 1. Получение и проверка запроса

1. Убедиться, что в теме или тексте письма явно запрошено удаление аккаунта Duet.
2. Сверить адрес отправителя с email аккаунта. Не просить пароль, код входа или другие секреты.
3. Если письмо пришло с другого адреса, попросить пользователя повторить запрос с регистрационного email или удалить аккаунт кнопкой внутри приложения, если вход ещё доступен. Не подтверждать владение по имени, фотографии экрана, сведениям о партнёре или содержимому аккаунта. Если ни один из двух способов недоступен, переместить письмо в `Удаление — ожидают подтверждения` и не удалять аккаунт до надёжного подтверждения.
4. Ответить, что запрос получен. Срок выполнения — не более 30 календарных дней после подтверждения владения аккаунтом.
5. После подтверждения оставить письмо в `Удаление — новые` до завершения удаления.

## 2. Найти аккаунт без изменения данных

Открыть PowerShell в корне проекта. В Supabase Dashboard открыть `Settings → API Keys`, создать или скопировать серверный `Secret key` и задать его только для текущего окна терминала:

```powershell
$env:SUPABASE_SECRET_KEY = Read-Host -MaskInput "Supabase secret key"
pnpm admin:delete-account -- --email user@example.com
```

Для старого проекта вместо `Secret key` можно временно использовать legacy-ключ `service_role`, задав его как `SUPABASE_SERVICE_ROLE_KEY`. Новый `Secret key` предпочтительнее.

Команда покажет email, ID и дату создания аккаунта, но ничего не удалит. Убедиться, что найден именно тот аккаунт, который указан в подтверждённом обращении.

## 3. Окончательно удалить аккаунт

Повторить email в параметре `--confirm`. Это защита от опечатки и случайного запуска:

```powershell
pnpm admin:delete-account -- --email user@example.com --execute --confirm user@example.com
```

Команда использует тот же порядок, что и удаление в приложении:

1. фиксирует список загруженных пользователем фотографий;
2. удаляет эти файлы из закрытого Supabase Storage;
3. удаляет связанные данные из базы;
4. удаляет аккаунт Supabase Auth и его серверные сессии.

Если команда завершилась ошибкой, не сообщать пользователю об успешном удалении. Исправить причину и безопасно повторить ту же команду: серверный процесс рассчитан на повторный запуск.

## 4. Завершение обращения

1. Повторно запустить команду без `--execute`. Ожидаемый результат: аккаунт не найден.
2. Удалить ключ из текущего окна терминала:

```powershell
Remove-Item Env:SUPABASE_SECRET_KEY
```

3. Ответить пользователю, что аккаунт и связанные данные удалены. Если совместные материалы без однозначного автора сохранились у партнёра, напомнить, что они больше не связаны с удалённым аккаунтом.
4. Переместить переписку в `Удаление — выполнено` и отметить дату удаления через 30 дней. По истечении срока удалить переписку из папки и корзины. Не создавать отдельную копию письма или содержимого аккаунта.

## Шаблон первого ответа

> Здравствуйте! Мы получили запрос на удаление аккаунта Duet. Для безопасности нам нужно подтвердить, что письмо отправлено с адреса, использованного при регистрации. После подтверждения удаление будет выполнено не позднее 30 календарных дней. Никому не отправляйте пароль или код подтверждения входа.

## Шаблон ответа после выполнения

> Здравствуйте! Аккаунт Duet и связанные с ним данные удалены. Повторный вход и восстановление удалённых данных невозможны. Остаточные записи могут сохраняться в резервных копиях базы Supabase до 7 дней и в технических журналах до 1 дня, после чего удаляются автоматически. Совместные материалы без однозначного автора могли остаться у партнёра без связи с удалённым аккаунтом.
